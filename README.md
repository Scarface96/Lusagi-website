# 🚀 Lussagi — Digital Marketing Agency Website

A responsive one-page website for **Lussagi**, a fictional digital content marketing agency, built with **HTML**, **CSS** and **JavaScript**.

## 📋 Page Sections

| Section | Content |
|---------|---------|
| **Home** | Hero banner — "Grow your business with us" |
| **Services** | Web design, SEO marketing, web hosting, digital marketing, ad campaigns, brand marketing |
| **About** | Agency story with stats (awards won, satisfied clients, projects completed) |
| **Portfolio** | Gallery of six sample projects |
| **Pricing** | Basic, Standard and Premium plans |
| **Reviews** | Client testimonials |
| **Contact** | Contact form and details |
| **Footer** | Quick links and social icons |

## ✨ Features

- 📱 **Fully responsive** layout for mobile, tablet and desktop
- 🍔 **Mobile menu** — hamburger toggle that opens/closes the navbar and closes automatically on scroll
- 🎨 Custom illustrations and icons (Font Awesome)
- Smooth single-page navigation between sections

## 📁 Project Structure

```
├── index.html       # All page sections
├── css/style.css    # Styles and responsive breakpoints
├── js/script.js     # Mobile menu toggle
└── images/          # Logos, illustrations, portfolio and service images
```

## 🚀 Getting Started

No build step — clone the repo and open `index.html` in your browser.

```bash
git clone https://github.com/Scarface96/Lusagi-website.git
```

## 📚 What I Learned

Structuring a multi-section landing page, responsive design with media queries, and simple DOM interactions with vanilla JavaScript.
